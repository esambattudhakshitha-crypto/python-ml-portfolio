# Python Student Marks Analysis

## Project Overview
This beginner-friendly Python project analyzes student marks using Pandas and visualizes average marks using Matplotlib.

## Objectives
- Store student marks in a Pandas DataFrame.
- Calculate total and average marks.
- Identify the top-performing student.
- Display a bar chart of average marks.

## Technologies Used
- Python
- Pandas
- Matplotlib

## How to Run
1. Install Python.
2. Install the required libraries:
   ```bash
   pip install pandas matplotlib
   ```
3. Run the program:
   ```bash
   python student_marks_analysis.py
   ```

Practiced data manipulation, basic statistical calculations, and data visualization using Python.
